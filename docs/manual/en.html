Getting started

Laptop Control Center stays near the Windows clock. Closing the window only hides the program; to exit, open the menu of the icon near the clock (right click or the applications key) and choose Exit.

The shortcuts work from any program, even with the window hidden. In the window, F1 opens this manual, F5 refreshes the readings, Escape hides the window and Control Tab moves between tabs.

The window menu bar has Program, Settings and Help. Alt opens the menu bar.

Overview

A list with all the computer readings, one per line: model, processor, usage, temperature, fan, memory, battery, brightness, power mode, disks, network and how long the computer has been on. Use the arrows to read and F5 to refresh.

The Programs using the most memory button says the eight that use the most memory.

Controls

Performance mode: silent, balanced or performance. It works on any laptop through the Windows power mode; on ASUS laptops it also changes the laptop's own mode.

Screen brightness: increase and decrease, in steps of 10 percent.

Fn Lock (on ASUS laptops that have it): on, F1 to F12 work directly without pressing Fn, which helps with screen reader shortcuts; off, they go back to being media keys. Control Alt F turns it on and off from any program.

Battery charge and keyboard light depend on the brand. ASUS (limit of 60, 80 or 100 percent, and 4 light levels), Lenovo (conservation, normal or fast charge, and 3 light levels), Dell and HP (BIOS options, Windows asks for permission) and Acer (health mode at 80 percent, Windows asks for permission). The tab says what works on your laptop.

Camera: uncheck Camera allowed to block the camera in every program, through the Windows privacy switch. Check it again to allow it.

Charge to 100 percent just this once: for a trip. When the battery is full, the program goes back to the previous limit by itself.

Turn off the keyboard light by itself: never, or after 30 seconds, 1, 2 or 5 minutes without touching the keyboard and mouse. It lights up again as soon as you use them.

Battery charge

Limiting the charge, for example to 80 percent, makes the battery last more years.

The limit only makes the battery stop charging when it reaches it. If it is already above, it does not discharge while plugged in: it waits until you use it down.

When the battery reaches the limit and stops charging, the program tells you that you can unplug it. While plugged in, the battery shortcut says how long until it is full.

Use the full charge before a trip.

Tools

Battery health: how much it still holds compared with the factory capacity, from the Windows report itself.

Wi-Fi: the network name and signal strength. Bluetooth and touchpad: turn on and off.

Internet test: download speed and response time, in about 15 seconds.

Disk health: whether the SSD or hard drive is healthy or has a warning.

What is slowing it down: the list of the heaviest programs right now. Delete, or the Close the selected program button, closes the chosen one. Windows and the screen reader are protected.

Full report: a text file in Documents with all readings, the battery, disks, Wi-Fi, the heaviest programs and the ones that start with Windows. Good to send to a technician.

Tests

Processor (one core and all), memory and disk, compared with the previous test.

Stress test: all cores at 100 percent for the chosen minutes. It stops by itself if the temperature goes over the limit, and says so.

Cleanup

See how much can be cleaned and clean temporary files older than one day (files in use are kept).

Free up memory: asks programs to give back the memory they are not using.

Programs that start with Windows: Space turns them on or off. It is the same control as Task Manager, so you can undo it there.

Advanced

Screen refresh rate: on screens that have it, choose between 60 Hz (less battery) and the highest one, such as 120 or 144 Hz (smoother picture).

Windows power plan: choose and activate one of the computer's plans.

Advanced options: processor usage limit (100 to 50 percent; lower is cooler and quieter, but slower), Eco or Standard graphics card (on ASUS laptops with a dedicated card) and power limit in watts (on ASUS laptops that have it). Each one explains what changes and asks before applying. To undo, go back to 100 percent or to Standard.

Updates

Check for program updates: lists the computer's programs that have a new version, through Windows winget, all checked. Space unchecks what you don't want. Update checked or Update all installs them without windows, one by one, and speaks the progress; some ask for Windows permission. Stop after the current one interrupts. The progress bar and the Status line show which program is being updated and how many are left, and every 30 seconds the program says it is still working, so you know it has not frozen.

Technical components, such as programming tools (Python, Node.js, Windows ADK) and Windows libraries (Visual C++, .NET), are left out of the list, because each program installs the version it needs. Check Also show technical components to see them.

Check for drivers: asks Windows Update for missing drivers. Install the drivers asks for Windows permission once and tells you if a restart is needed.

Shortcuts and options

Change the key of each shortcut: choose the action, the key and press Change the key. The program warns if the key is already in use.

Sounds, start hidden, start with Windows, language (Portuguese, English or Spanish), check for updates and About.

Sounds and alerts

A sound and speech when the charger is plugged in or unplugged, when the battery reaches the limit, when it drops below 20 percent unplugged and when the processor goes over 85 degrees.

A sound for each performance mode, for the keyboard light (higher pitch for brighter) and for brightness. Sounds can be turned off in Shortcuts and options.

Portable version

In the installer you can choose Portable: the program goes to a folder or USB drive, with no shortcuts and no uninstaller. Settings are kept in the dados folder, next to the program.

When a new version comes out, the portable version tells you and opens the download page.
